# AI-Powered-Mobile-Addiction-Risk-Prediction-System


**AI-Powered Mobile Addiction Risk Prediction System**

Developed an end-to-end machine learning application to predict users' daily screen time and assess mobile addiction risk using smartphone usage patterns and behavioral data. The project covers the complete machine learning workflow, including data preprocessing, feature engineering, model experimentation, experiment tracking, API development, and an interactive web application for real-time predictions.

**Key Contributions**

• Performed comprehensive Exploratory Data Analysis (EDA) to identify trends, patterns, and relationships within the dataset.

• Designed a reusable data preprocessing pipeline that included data cleaning, feature transformation, and feature engineering.

• Engineered domain-specific features such as Data Usage per Hour, Battery Drain per Hour, Device Stress Score, and Heavy Gamer Indicator to improve model performance.

• Trained and evaluated multiple machine learning models, including Linear Regression, Random Forest, XGBoost, LightGBM, and CatBoost.

• Compared model performance using R² Score, Adjusted R², RMSE, and MAE to identify the most effective predictive model.

• Used MLflow to track experiments, compare model performance, and manage model versions.

• Developed a FastAPI REST API for serving real-time predictions.

• Built an interactive Streamlit application that predicts daily screen time, estimates mobile addiction risk, and provides personalized digital wellness recommendations based on user inputs.

• Serialized the trained model using Joblib for efficient inference and deployment.

• Containerized the application using Docker to ensure consistent execution across different environments.

• Implemented a GitHub Actions workflow to automate project validation and streamline development.

**Technologies**

Python, Pandas, NumPy, Scikit-learn, XGBoost, LightGBM, CatBoost, MLflow, FastAPI, Streamlit, Docker, GitHub Actions, Joblib, Jupyter Notebook

**Outcome**

This project demonstrates practical experience in machine learning, feature engineering, experiment tracking, API development, model deployment, containerization, and building end-to-end AI applications. It highlights the ability to develop scalable machine learning solutions that move beyond model training to real-world application.
